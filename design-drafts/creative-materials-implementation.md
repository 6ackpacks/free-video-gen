# 素材、视频方向与按摩特色模板

行业 → 模板类型 → 动作保持不变。数字人商品口播是独立类型；商品宣传、开箱测评、一镜到底是服务／产品展示中的视频方向。按摩护理展示是专属类型，保留原动作和旧项目的 massage:service 标识，另提供通用产品展示，避免混用护理底图。

## 实际功能

- 产品图、人物图、场景图分开上传、选择和保存；产品名称、确认卖点、口播稿、声音和音乐随项目保存。
- 关键帧生图带上三类参考；主体参考视频提交同时带上关键帧和这些素材，初始画面模式仍只提交合成关键帧。
- 视频方向进入提示词规则，不再只是参考详情。按摩部位、姿态与接触要求同样参与提示词与底图。
- 数字人口播项目可以执行。模型口播启用视频服务声音；已有配音模式使用专用 wan2.2-s2v 适配器，提交真实 image_url 与 audio_url，正常轮询生成结果。
- 专用接口需北京地域百炼密钥、DASHSCOPE_WORKSPACE_ID 和公网HTTPS MP3／WAV地址；配置不全时不会显示成可用路由。业务空间ID可在模型设置中保存，重启加载。模型口播不需要此业务空间配置。
- 资料不完整时明确提示并阻止制作；修改商品或素材使旧草稿失效；使用中的角色素材不能被物理删除。

## 边界

当前每个动作仍生成独立短视频，使用当前服务支持的时长。商品宣传与测评通过单条短片提示词表达相对节奏；一镜到底是同一个生成任务内的连续镜头。没有实现来源平台中的30/60/90秒多任务编排、逐段首尾帧接力、独立TTS／BGM生成或最终多片段合成，不应把本次功能描述为原版Flova完整编排引擎。模型口播也不保证逐字精确口型；需要既有音频驱动时选专用接口。

来源模型偏好不是硬编码替代方案；本应用明确使用用户当前选择的服务。未调用付费上游进行出片验证。

## 验证

114项项目测试通过，含素材保存恢复、卖点修改后草稿失效、实际任务素材传递、关键帧多图调用、配音驱动接口请求及状态解析、无配置时拦截、按摩动作隔离。

E2E覆盖三类素材选择、真实文件选择器与模拟产品图上传、口播项目创建、文本与素材恢复、资料缺失后按钮状态更新、两种口播模式、视频方向应用、按摩护理要求及响应式布局。生成提交与素材业务写入隔离，无付费请求。测试脚本位于 scripts/e2e。
