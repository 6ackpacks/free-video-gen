# 外部 Skill 归入模板的方案

> 历史阶段记录。后续素材与口播的实际实现、能力边界和最新测试见 creative-materials-implementation.md。

行业 → 模板类型 → 动作的现有结构保留。模板中心仍只展示环境展示、服务／产品展示、顾客故事和行业特色，通用模板不按行业重复建卡。

按最新确认，数字人商品口播独立成为一个模板类型；商品宣传、开箱测评、一镜到底作为「服务／产品展示」中的视频方向。它们不是普通动作，不加入现有批量提交队列。行业按实际产品和业务匹配，不能因为跨行业共享就虚构门店的商品或测评。

| 制作方案 | 必要素材 | 成片逻辑 |
| --- | --- | --- |
| 商品宣传短片 | 产品照片、确认卖点 | 使用场景与特写分镜 + 音频 + 剪辑 |
| 数字人商品口播 | 产品照片、人物要求、口播稿 | 同一关键帧 + 音频驱动口型 + 分句拼接 |
| 开箱测评种草 | 产品照片、真实产品信息 | 开箱20%、体验60%、总结20% + 自然旁白 |
| 一镜到底广告 | 主体与场景参考、连续动作 | 选择衔接模式 → 逐段生成和确认 → 连续成片 |

## 与现有生成逻辑的边界

当前动作仍分别生成一条视频，数量配置沿用原逻辑。新方案内部的分镜属于同一成片，不计作多个独立获客动作。未来接入时，每次实际生成仍需用户选择服务、比例、画质、图片用途；支持能力不足的服务不能提交或静默降级。

来源中的 text_editor、storyboard_designer、media_generator、video_assembler 是其平台工具名称，不能当成本项目已有能力。模型名称是来源偏好，版本、时长、分辨率与价格都需接入时另行验证。四项目前均为待接入流程，界面无执行按钮。

## 归纳时解决的规则冲突

- 数字人口播以单场景、单构图、同一关键帧为准，去掉原文通用段落中的双人镜头／越肩镜头切换要求。
- 首帧衔接和前段视频参考作为两条独立分支；重制中间段要根据所选模式检查实际拥有的资产和首尾帧能力，不能假定下一段总有 start_frame 图。
- 普通图生视频不自动替代音频驱动口型；多模态测评不自动改为首帧生成。
- 模型生成片段的分辨率与最终导出分辨率分开，升采样不标作原生高画质。
- 产品功能、价格和比较结论以用户确认的事实为准，保留真实品牌包装；演示产品明确标注。
- 源文档中的暂停节点保留为未来流程的审阅节点，本次整理不执行其中的生成指令。

## 来源范围

商品宣传与一镜到底附件包含完整流程；第三份附件混有页面导航、营销价格和许多 Skill 卡片，实际完整正文是开箱测评。仅有简介的电商视觉全案、TVC、Logo创意等未伪装成可执行流程导入。数字人口播来自本次用户贴出的完整正文。

结构化定义：studio-workflow-recipes.js。界面：模板中心 → 服务／产品展示 → 视频方向；数字人商品口播可在独立卡片查看。所有模板入口统一经过行业确认；数字人口播尚未接入生成能力，确认行业后查看流程，不创建虚假的可执行项目。
