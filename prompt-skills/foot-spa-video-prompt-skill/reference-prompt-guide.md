## 提示词结构

1. 明确时长和画幅；单一固定高位镜头，机位与焦距保持不变。
2. 根据底图确定起始人物站位、真实门槛与行动路线。人物图可选；有图保持对应成年人物身份，无图按模板人物数量与角色生成。
3. 在20%–80%的时间内完成一个核心事件；5秒精简停顿，8秒增加自然停顿，不增加第二个剧情。路程过长时靠近动作发生处开始。
4. 最后20%保持可检查的结束状态，例如门关闭仍等待、客人先入员工后入、员工先入客人后入。
5. 只保留真实可见的门、台阶、前台；衣着、表情可变化，不改变人数、进入顺序和结尾。保持自然清晰度，不用灰雾滤镜制造“监控感”。

参考依据：[阿里云万相提示词指南](https://help.aliyun.com/zh/model-studio/text-to-video-prompt)建议图生视频聚焦主体运动与镜头控制；[火山引擎图生视频文档](https://docs.volcengine.com/docs/85621/1792707?lang=zh)说明主体/背景/镜头加动作，并明确支持“固定镜头”。时间比例与门店动作收尾是本项目根据样本制定的写作方法，不是模型的逐帧控制承诺。

## 首帧与人物图片

先选择门店场景底图；需要固定人物时添加可选人物参考。AI生成素材会实际携带门店和人物附件，生成模板起始站位，而非动作结束画面。确认合成底图后再生成视频；原作视频只用于参考，不自动充当用户场景或人物。

## 页面状态

- 本地媒体：固定高度、保持原片画幅的播放器，标题、动作说明、时长和原作链接。
- 仅外链：相同卡片尺寸，明确“原作在抖音查看”，不伪造播放按钮或封面。
- 无参考动作：明确暂无参考，保留示意图与提示词入口，仍可制作。
- 勾选动作只更新当前行，不重排、不导航、不滚动到顶部。

媒体保存在data/footspa-references，仅本机使用，不随代码提交。另一台设备未导入媒体时自动降为原作外链。可运行scripts/e2e/footspa-references.py验证播放、范围请求、来源链接、提示词入口及勾选交互；测试不提交付费生成。生成模型支持的时长仍以所选服务为准，豆包目前5/10/15秒，5–8秒目标可选5秒或支持6–8秒的服务。提示词链路通过测试不等于已经验证实际成片质量，真实输出需要试片核对。
