# 给开发 Agent 的实现要求

本目录的 SKILL.md 与 14 个动作模板是大模型生成提示词的范围约束。模板不是成片提示词的固定拼接结构。

## 生成流程

1. 固定底图，分析真实空间，并按门、路线、人数证据判定模板是否可用。
2. 用户选择模板和数量，右侧进入提示词页。只保留一个创作想法输入框，留空即可直接生成。
3. 将模板参考、真实空间、核心事件、角色关系、结束状态、时长、画质和声音约束交给提示词大模型。
4. 大模型直接创作完整最终提示词。允许措辞、叙述顺序、表情、节奏和细微互动多样化，不要求逐字照抄动作模板。
5. 按数量显示逐条可编辑的完整结果，每条支持勾选和全选。
6. 右侧确认后直接提交所有所选提示词，使用编辑后的全文，不再额外等待首条试片放行。成片仍可试览和下载。

## 约束与界面

底图是真实空间依据，不增造门、通道或物件。一次使用一个兼容模板，保持核心事件、人物数量、身份关系与结束状态。遵循 SKILL.md 的画质、音乐与人物规则。

所有内容类型只提供一个选填的创作想法输入框，以及生成、改写、可编辑结果。不要设计成聊天问答。输入要求必须传给模型，并影响最后采用的提示词。

最终全文由模型撰写，程序只做结构校验和记录，不自动插入不可改写的动作正文或固定段落。记录模板 ID、底图 ID、用户要求、人物信息及最终文本。设置变化后提示用户重新生成；保留旧记录可查看。
