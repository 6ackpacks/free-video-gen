# 足浴会所固定镜头视频提示词 Skill

## 目标

先固定一张底图，再分析底图中的空间。最终视频提示词由三部分组合：底图场景描述、一个已确认且适配场景的动作模板、人物外貌与穿搭描述。动作模板是固定资产，生成模型不得改写、扩写、删减、调换动作顺序或改变结束状态。

模型主要负责识别底图，并为本次视频补充人物外貌和服装。人物与穿搭可以变化，动作来自模板库。通过不同人物、服装与动作模板的组合，形成彼此有差异的视频。

## 处理流程

1. **固定底图**：本批视频使用用户提供或前端指定的底图。视频提示词必须保留底图中的空间结构、透视、光线、门、植物、装饰和构图。
2. **分析场景**：识别场景类型、可行走区域、真实存在的房门及其位置、人物可进入/离开的画面方向、固定机位视角。不得虚构底图中不存在的门或通道。
3. **选择动作模板**：由用户在前端选择，或由系统在适配场景的模板中抽选。若模板与底图空间冲突，跳过该模板并选择可执行的兼容模板。模板正文及其结束状态必须原样保留。
4. **生成角色与穿搭**：按人物数量和模板需要生成成年角色的外貌、体型、发型和服装。穿搭可以随机组合，但不能覆盖或改变动作。
5. **编译视频提示词**：把底图描述、模板动作、人物穿搭和全局固定画质/声音要求组合成提示词。只补充连接语，不改动作语义。
6. **输出并记录**：输出视频提示词，并记录使用的底图 ID、动作模板 ID、人物/穿搭组合和生成结果，避免短期重复。

## 绝对固定规则

### 底图与镜头

- 视频开始前底图已经固定；提示词只描述保持底图原有画面，不重新设计场景。
- 固定高位摄像机视角，全程静止；画面构图、透视和机位不变，只有人物运动。
- 仅允许人物与底图中真实存在的物件发生互动。

### 画面质感

每一条视频提示词都必须包含以下质感要求，可调整语序，不得遗漏关键特征，也不要使用“CCTV”一词：

> 画面呈现老旧摄像头拍摄质感，轻微模糊、灰蒙蒙一层雾感、低对比、噪点和视频压缩痕迹，保留底图已有的时间戳与通道编号。

保持彩色画面，不额外生成新的监控界面或标识；底图已有的时间戳与通道编号尽量保留。

### 声音

- 每段视频都必须有优雅、舒缓的纯音乐，无歌词。
- 人物可以说话、交流，画面中允许出现自然嘴型；音轨里不得出现可听见的人声、对白、耳语或歌词。
- 动作模板中的“询问/交谈”均以无声嘴型呈现。

### 女性人物与服装

- 女性角色均为年轻成年女性，外貌漂亮、身材匀称或曲线明显，气质优雅自然。
- 服装以合身、修身、能够呈现身材线条为主，不选宽松款。保持得体，不走光、不透明、不夸张低胸、不出现不必要的裸露。
- 服装不局限于制服。根据批次和场景轮换修身长裙、挂脖裙、细肩带长裙、单肩裙、短袖上衣配短裙、修身 T 恤配包臀裙、修身连衣裙等。
- 可变化颜色、领型、袖长、裙长、开衩位置、发型、鞋履和小配饰。明确露背是否有面料覆盖、开衩高度等关键结构。
- 同一视频中的多位女性要有可区分的造型；不同视频尽量避免重复相同的服装组合。

### 男性客人

- 男性客人是成年男性，穿日常休闲装，通常短袖 T 恤、Polo 衫、休闲短裤、牛仔裤或普通长裤；不穿正装、西装或商务套装。
- 外貌自然普通，体型可偏胖、微胖、壮实或瘦小；不要描述成高大、帅气、纤瘦的男模形象。
- 具体体型在不同视频间轮换，避免每条都一样。

## 动作模板选择与约束

- 每条视频使用一个主动作模板。模板库见 [`actions/`](actions/) 文件夹，编号 01–14。
- 模型不得自行发明替代动作，不得为模板增加拥抱、牵手、搂腰等动作。
- 必须保持模板中的人物移动方向、交互次序和结束状态；动作模板里的禁止项同样必须遵守。
- 根据底图可见空间判断模板是否可执行。模板未指定穿搭时，模型只填人物与服装变量。
- 一条视频不拼接多个模板；如要生成新动作，先由用户确认并新增独立模板文件。

## 推荐输出结构

```text
时长与画幅（如产品侧已固定，则不要重复冲突参数）
保持底图与固定机位
人物外貌、体型和穿搭
所选动作模板原文（不得改写动作）
固定老旧摄像头画质描述
固定声音描述：只有优雅纯音乐，无可听见人声
```

## 兼容性与多样性

- 可抽选模板必须同时满足底图空间兼容、人物数量兼容、动作在时长内可完成。
- 多人动作控制人物活动数量；模板 12 等候选群像动作应严格保持其他角色静止，避免模型给每个人额外编动作。
- 批量生成时避免近期重复相同动作模板、女性造型组合、男性体型组合。优先轮换动作、领型、裙型、颜色、发型和人物数量。
- 人物与服装可以随机组合；动作模板只在兼容模板集合里抽选，不允许用随机化改动模板正文。
