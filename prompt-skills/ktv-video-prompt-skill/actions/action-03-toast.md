# 动作模板 03

## 固定动作正文

一名年轻成年女性与两名成年男性围坐在沙发和矮桌旁，各自拿起桌上已有的饮料杯，身体微微前倾，在桌面上方轻碰一次杯。三人自然微笑，随后把杯子收回到自己身前，不强迫饮酒，不表现醉态。

## 结束状态

三人碰杯后把杯子自然收回，仍围坐在桌边。
