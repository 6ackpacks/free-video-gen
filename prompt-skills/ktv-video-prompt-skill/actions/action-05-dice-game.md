# 动作模板 05

## 固定动作正文

一名年轻成年女性与一名成年男性坐在矮桌两侧，女性双手轻摇桌上已有的骰盅后放稳并打开，两人同时低头查看结果，再自然抬头笑起来。骰盅始终留在桌面上，不出现赌博筹码或现金。

## 结束状态

两人同时看向打开的骰盅并自然笑起来。
