# KTV 内容模板

只使用底图真实存在的屏幕、沙发、桌面、麦克风、点歌台、前台、房门与通道。人物全部为成年人；女性限定 22–30 岁，穿鲜艳时尚但常规领、完整遮挡胸线且不透明的私服。允许正常唱歌、碰杯、玩骰子、聊天和庆祝；禁止醉酒失控、强迫饮酒、性暗示、脱衣、抚摸、亲吻、打架或危险动作。

每次视频只选择一个 `actions/` 动作文件，动作顺序和结束状态不得由人物提示词模型改写。
