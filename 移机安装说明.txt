视频工作台｜Windows 移机安装

一、环境要求
1. 安装 Node.js 24 或更新版本：https://nodejs.org/
2. 安装 PowerShell 7（命令名 pwsh）：https://learn.microsoft.com/powershell/
3. 启动你的代理/VPN。当前 project.env 默认代理地址为 127.0.0.1:7897；若新电脑端口不同，请用记事本修改 HTTP_PROXY 和 HTTPS_PROXY。

二、首次启动
1. 解压整个 video-workbench 文件夹，不要只打开 ZIP 内的文件。
2. 在项目目录运行：pwsh -File setup-key.ps1
3. 按提示输入 APIMart 密钥；TokenDance 和阿里云百炼密钥按需要选填。密钥用当前 Windows 账户加密保存在 data/*.dpapi，不会写入源码。
4. 双击“启动工作台.cmd”。桌面应用会直接打开；浏览器模式可访问 http://127.0.0.1:4173/ 。

三、使用流程
1. 上传普通底图。系统先用视觉模型读取真实空间并生成场景档案。
2. 如需监控风格底图，点击“加工为老旧监控底图”；每张结果会使用不同时间戳，然后自动重新分析场景。
3. 选择一个兼容动作模板，或使用兼容模板随机抽选。
4. 选择视频模型、API 额度来源、时间、数量和分辨率。分辨率默认 480P。
5. 先生成一条试片，确认后再生成本批剩余视频。

已接入的视频路由：wan3.0-video（TokenDance / 阿里云百炼）、Grok Video（APIMart）、豆包 Seedance（本机账号池）。豆包提示词会明确带上所选视频时长。

四、数据说明
此移机包不包含旧电脑的 API 密钥、任务记录或视频缓存。新电脑首次运行时会自动创建 data 文件夹。
