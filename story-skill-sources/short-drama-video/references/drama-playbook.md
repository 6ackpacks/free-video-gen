# 短剧带货戏剧手法手册
本文件提供5种标准短剧类型的创作规范、戏剧结构和节奏铁律，供生成创意方案时参考。每种类型都有明确的核心情绪、适用产品和典型结构，AI应严格按用户选定的类型进行创作。
## 一、五大短剧类型规范
### 1. 霸道总裁
- **核心情绪**：被低估→霸总暗中护航→无声翻盘→全场震惊
- **适用产品**：3C数码、高端外设、轻奢品牌、男士护理、办公效率工具、商务配件
- **典型结构**：新人/底层员工被高管当众羞辱→霸道总裁暗中递出产品→主角用产品无声完成不可能任务→反派哑口无言，霸总淡然护短
- **转化句风格**：淡定霸气，高级感，如"无声才是最高级的战斗力"
- **视觉参考**：韩剧职场剧质感、冷白日光灯、权力落差构图、总裁出场慢推镜头
- **关键人物三角**：被低估的主角（新人助理）、施压反派（女总监/老员工）、暗中护短的霸总（关键见证者）
### 2. 家庭伦理
- **核心情绪**：被误解/道德绑架→用产品自证→反转打脸→长辈尴尬
- **适用产品**：家居家电、母婴用品、食品、日用品、智能家居、小家电
- **典型结构**：婆婆/长辈当众指责晚辈（噪音/浪费/不懂事）→晚辈不辩解，默默拿出产品→产品证明真相（噪音源是长辈自己的/产品其实很实用）→全家目光转向长辈，长辈尴尬凝固
- **转化句风格**：温和但有力量，共情强，如"加班再晚，也不吵家里人"
- **视觉参考**：抖音家庭短剧手持真实感、暖黄室内灯光、站坐高低权力构图、反应特写
- **关键人物三角**：被误解的晚辈（儿媳/女婿）、施压长辈（婆婆/丈母娘）、沉默旁观者（丈夫/妻子）
### 3. 古装宫斗
- **核心情绪**：位卑者被当众羞辱→拿出现代产品秘密武器→效率碾压→高位者失语
- **适用产品**：国潮品牌、老字号、美妆护肤、食品茶饮、文创周边、古风联名
- **典型结构**：妃嫔/权贵当众刁难低位女官/侍女，限时施压→低位者从袖中取出现代产品（古今错位）→静音高效完成不可能任务→第二天权贵看到成果当场凝固
- **转化句风格**：符合古风角色身份，带韵味，如"宫里不比别处，动静大了招祸"
- **视觉参考**：《甄嬛传》色彩服装质感、《延禧攻略》低饱和构图、烛光氛围、4:3画幅短剧快切节奏
- **关键人物三角**：低位但有实力的主角（掌笔女官/侍女）、高位反派（华妃/贵妃）、困惑见证者（太监/宫女）
### 4. 职场爽剧
- **核心情绪**：被质疑能力→用产品高效完成→当众打脸→全场服气
- **适用产品**：办公软件、效率工具、3C数码、职业装、咖啡/功能饮料、职场外设
- **典型结构**：被老板/同事当众质疑能力，限时死线→主角默默拿出产品高效操作→提前完美完成任务→老板/同事表情从傲慢变震惊
- **转化句风格**：专业冷静，爽感足，如"无声才是职场最大声的反击"
- **视觉参考**：《三十而已》职场灯光对比、中近景反应切镜、办公室真实布景感、冷暖色对比
- **关键人物三角**：被施压的主角（职场新人/社畜）、傲慢反派（老板/主管/老员工）、围观见证者（同事）
### 5. 悬疑反转
- **核心情绪**：诡异悬念→观众以为主角异常→产品揭晓真相→原来是高手
- **适用产品**：黑科技数码、新奇产品、功能性外设、无线智能产品、创意好物
- **典型结构**：旁观者发现主角行为诡异（对空气操作/深夜异常），以为精神有问题，准备录下来笑话→揭晓产品真相（无线/静音/隐形特性解释了所有诡异）→主角早已完成任务，旁观者震惊
- **转化句风格**：悬念揭晓感，酷，如"不发声也能赢"
- **视觉参考**：《黑客帝国》冷调侧光、手持晃动镜头、《网络谜踪》手部特写、深蓝暗影氛围
- **关键人物三角**：被误判的主角（隐藏高手）、制造误判的反派（看热闹的同事/路人）、无第三方见证（双人戏更紧凑）
## 二、10步戏剧结构详解
每个创意方案必须包含以下10个戏剧要素，这是短剧带货的黄金结构：
1. **2秒钩子**：开场必须有冲突——有人在骂/嘲笑/质疑/施压，画面和台词同时冲击，让观众停不下来
2. **施压关系**：明确谁压谁，压迫感要具体（当众、在客户面前、在家人面前）
3. **错误判断**：反派基于表象做出错误判断（"你不行""这破东西""你疯了吧"）
4. **压力锁**：制造不可逆的压力——倒计时、围观人群、赌注、最后机会
5. **主角隐藏选择**：主角不辩解，默默拿出/使用产品，这是观众期待的"要开始了"时刻
6. **产品剧情功能**：产品不是道具，是剧情反转的引擎——它让不可能变可能
7. **爽点**：反转发生的具体瞬间，要视觉化（不是"他赢了"，而是"报表从打印机出来完美无误"）
8. **可见证明**：必须有肉眼可见的证据——数量对比、表情变化、数据结果、产品特写
9. **见证者反应**：反派/围观者的表情变化是爽感放大器——从嘲讽→震惊→怀疑人生
10. **转化句**：最后一句话必须包含品牌/产品名，是slogan也是记忆点，由主角在剧情中说出
## 三、内容路线（创意容器）
内容路线是戏剧的"壳"，决定了故事的超现实程度和视觉风格：
| 路线 | 说明 | 视觉特点 |
|------|------|----------|
| Deadline/Competence Win | 时间压力下用产品完成不可能任务 | 快节奏剪辑、倒计时、操作特写 |
| 古今错位 | 古代/大人物进入现代场景 | 服装反差、语言反差、场景反差 |
| 身份反转 | 看似普通人其实是大佬/专家 | 服装变化、气场变化、周围人态度变化 |
| 真香定律 | 先嫌弃后沉迷 | 表情大转变、吃/用的特写、停不下来 |
| 以貌取人 | 以穿着/外表判断，被现实打脸 | 穿着对比、环境对比、势利眼表情 |
| 误解揭示 | 因为某个误会产生冲突，产品解开误会 | 恍然大悟的表情、悬念揭晓 |
| 关系认知反转 | 家庭/职场关系中的道德绑架反击 | 权力关系构图、情绪节奏变化 |
| 悬疑审判 | 旁观者偷窥视角，最后揭晓真相 | 冷调侧光、手持晃动、暗影氛围 |
## 四、10秒节奏铁律（单段一气呵成）
10秒单段生成，总时长极紧，因此**必须删掉一切过渡镜头、铺垫台词和空镜**，每个时间段只承载一个核心信息，四阶段层层推进：
### 0-2秒（钩子期）：必须出冲突
- 必须在第1秒就有人说话/骂人/摔东西，画面有冲击力
- 不能铺垫，不能慢慢介绍场景，不能有环境交代镜头
- 反派台词直接抛出来（一句短句即可），压力立刻给到主角
- 画面：中近景对峙，冲突双方同时入镜
### 2-5秒（施压期）：压力升级+产品登场
- 反派加码施压，主角陷入困境，冲突加剧
- 观众共情主角，期待反转
- 产品在本阶段末尾首次出现（主角默默拿出/换上），必须有清晰特写
- 画面：从反派施压切到主角反应，最后落到产品特写
### 5-8秒（反转期）：产品发挥作用+爽点高潮
- 产品开始发挥作用，反转拉开序幕
- 核心爽点在此阶段呈现，必须有视觉冲击
- 可见证明+见证者反应同时出现
- 画面：产品使用特写→效果呈现→反派/见证者表情崩塌
### 8-10秒（收尾期）：口播转化
- 主角收尾，说出转化句（含品牌/产品名）
- 画面定格在产品或主角自信表情
- 不要拖沓，说完即止，只有约2秒说话时间
- 画面：主角正面+产品同框，干净收尾
## 五、口播转化句写作原则
1. **必须包含品牌/产品名**：这是广告，不是纯短剧
2. **必须由角色在剧情中说出**：不是旁白，不是字幕，是角色的台词
3. **必须符合角色身份**：
   - 霸道总裁型主角→淡定霸气
   - 古装宫斗型主角→古风韵味
   - 家庭伦理型主角→温和坚定
   - 职场爽剧型主角→专业冷静
   - 悬疑反转型主角→冷静神秘
4. **必须简短有力**：视频最后只有约2秒说话时间，控制在12字以内
5. **必须是记忆点**：观众看完能记住这句话，甚至愿意复述
6. **好例子**：
   - "无声才是最高级的战斗力"（霸道总裁型）
   - "加班再晚，也不吵家里人"（家庭伦理型）
   - "无声胜有声"（古装宫斗型）
   - "无声才是职场最大声的反击"（职场爽剧型）
   - "不发声也能赢"（悬疑反转型）
7. **坏例子**：
   - "XX鼠标真的很好用大家快来买"（太硬广）
   - "选择XX，选择品质生活"（太空洞）
   - "XX店欢迎您"（像广播不是台词）
## 六、产品植入原则
1. **产品是剧情引擎，不是贴脸广告**：没有这个产品，反转就不成立
2. **产品必须有特写时刻**：2-5秒之间必须有产品的清晰特写（首次登场）
3. **产品功能要戏剧化**：不是"这个鼠标很静音"，而是"老板站在身后都听不到操作声"
4. **产品外观要忠于素材**：如果用户上传了素材，产品颜色/形状/包装/品牌标识必须匹配
5. **不要罗列卖点**：10秒聚焦一个核心卖点，用戏剧证明它，不要念参数
6. **产品命名统一**：视频提示词中统一称为"产品1"，全片保持外观一致
## 七、人物形象提示词要求（本 skill 不生成人物参考图）
人物外观不再靠形象图锁定，全部由视频提示词文字定义，因此方案内部必须把每个角色写足：
1. **颗粒度到"能画出来"**：年龄+性别+脸型五官+发型发色+肤色体型+服装（款式/颜色/材质/配饰）+气质+习惯动作
2. **每个角色一个记忆锚点**：一眼能认出的标志性特征（疤痕、耳钉、宽边戒指、特定眼镜等）
3. **全片逐字复用**：4个时间段的人物描述必须完全一致，不换装、不换发型、不改年龄、不换气质
4. **形象要符合短剧类型**：霸总戏的角色要有权力质感，家庭戏的角色要有生活气，古装戏的服装要符合朝代氛围
5. **避免同脸**：主角与反派必须有明显的年龄差/体型差/造型差，防止模型生成时两张脸趋同
