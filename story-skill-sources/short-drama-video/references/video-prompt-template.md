# 视频生成提示词模板
## 使用说明
本文件提供视频生成提示词的标准结构模板。AI在构建视频提示词时，必须严格按照以下7个部分的顺序和结构来组织，确保提示词的完整性和一致性。
⚠️ 本 skill **不生成人物形象参考图**，第四部分「人物定义」是人物外观的唯一依据，必须写足颗粒度，详见第四部分说明。
---
## 提示词标准结构
### 第一部分：基础参数
```
时长：10秒，比例：4:3。生成一条4:3画幅短剧剧情带货视频。
```
### 第二部分：视觉基调
描述整体视觉风格、参考作品、镜头语言、光线氛围：
```
视觉基调参考{参考作品1}的{风格特征}、{参考作品2}的{风格特征}，以及短剧快节奏切镜风格，镜头以中近景对峙、手部特写和反应切镜为主，节奏紧凑，反转处用慢镜落地。
全片{主光源/色调}为主，画面为真人实拍质感，不要动画或CG质感。
4:3画幅横向信息量更大，构图以人物中近景/半身入镜为主，主体占画面1/3以上，避免大远景导致人物过小。
```
**不同类型的视觉基调参考：**
- **霸道总裁**：韩剧职场剧的冷白日光灯灯光、权力落差构图、总裁出场慢推镜头
- **家庭伦理**：抖音家庭短剧手持真实感、站坐高低权力构图、暖黄室内灯光
- **古装宫斗**：《甄嬛传》低饱和宫廷色调与服装质感、《延禧攻略》构图与烛光氛围
- **职场爽剧**：《三十而已》职场冷暖灯光对比、中近景反应切镜、办公室真实布景感
- **悬疑反转**：《黑客帝国》冷调蓝绿侧光、手持晃动镜头、《网络谜踪》手部特写
### 第三部分：产品定义
基于用户素材识别产品外观，统一命名为"产品1"，详细描述外观特征（无用户素材时，按产品名描述其标准外观）：
```
将图片1中的产品外观定义为产品1：{产品品牌名+产品名}，{颜色+材质+形状+关键特征+品牌标识位置}，全片产品1的{核心外观特征}保持一致。
```
**示例：**
```
将图片1中的产品外观定义为产品1：忆捷EAGET无线蓝牙鼠标，银灰色亮面外壳、超薄圆角长椭圆形、黑色滚轮与DPI调节键、底部印有"EAGET"品牌标识，全片产品1的银灰色亮面质感和圆角超薄造型保持一致。
```
### 第四部分：人物定义（唯一依据，必须写足）
本 skill 不生成人物形象参考图，因此**人物外观完全由本部分文字决定**。每个角色必须写到"能直接画出来"的颗粒度，且4个时间段里的描述**逐字一致**（不换装、不换发型、不改年龄、不换气质）。
```
主体1是{角色名}，约{年龄}岁{性别}，{脸型+五官特征+发型发色+肤色+体型}，穿{服装款式+颜色+材质+配饰}，{姿态/气质描述}，记忆锚点为{一眼能认出的标志性特征}，关系功能是{剧情中的角色定位}。
反派1是{角色名}，约{年龄}岁{性别}，{脸型+五官特征+发型发色+肤色+体型}，穿{服装款式+颜色+材质+配饰}，{姿态/气质描述}，记忆锚点为{标志性特征}，关系功能是{剧情中的角色定位}。
关键见证者是{角色名}，约{年龄}岁{性别}，{脸型+五官特征+发型发色+肤色+体型}，穿{服装款式+颜色+材质+配饰}，负责{剧情中的作用}。
```
**示例：**
```
主体1是林默，约28岁男性，窄长脸、单眼皮薄唇、高鼻梁，黑色短发后梳，肤色偏白，身材清瘦挺拔，穿深灰修身衬衫配黑色西裤、一副细框金属眼镜，站姿笔直、说话时习惯性推一下眼镜，记忆锚点为左眉尾一道浅疤，关系功能是被当众质疑的新人。
反派1是赵总，约45岁男性，方圆脸、浓眉、嘴角常年下压，两鬓灰白的大背头，肤色偏黄，中等身材偏壮，穿黑色高领毛衣配深蓝西装外套、腕上一块大表盘手表，说话时喜欢双手撑桌俯视对方，记忆锚点为右手无名指一枚宽边银戒，关系功能是施压者。
```
### 第五部分：场景定义
详细描述场景环境，包含地点、陈设、光线氛围：
```
场景是{具体地点}，{环境陈设描述}，{光线氛围描述}。
```
**示例：**
```
场景是深夜高档写字楼开放式办公区，冷白日光灯，大落地窗外是城市夜景，工位上有电脑、文件、咖啡杯。
```
### 第六部分：分时段详细描述（核心）
按0-2秒、2-5秒、5-8秒、8-10秒四个时间段，每段包含：拍法、画面内容、商品露出、声音。
⚠️ 10秒时长极紧，每段只承载一个核心信息，开场即冲突，禁止铺垫和空镜。
#### 0-2秒（钩子期）
```
0-2秒：
拍法：{镜头角度+景别+运镜方式+构图说明}
画面内容：{第1秒就发生的冲突，谁在做什么，关键动作和表情}
声音：{谁说+语气+台词内容}，（背景音乐说明），<音效1>。
```
#### 2-5秒（施压期+产品登场）
```
2-5秒：
拍法：{镜头角度+景别+运镜方式+构图说明}
画面内容：{施压如何升级，主角反应，产品在末尾首次出现，产品特写}
商品露出：{产品1在画面中的位置、状态、可见特征}
声音：（背景音乐变化），<音效>，{人物台词}。
```
#### 5-8秒（反转期+爽点高潮）
```
5-8秒：
拍法：{镜头切换方式+多角度描述+节奏说明}
画面内容：{产品如何发挥作用，爽点如何呈现，可见证明是什么，见证者/反派反应}
商品露出：{产品1在画面中的使用状态、可见特征}
声音：{人物台词/反应}，（背景音乐节奏变化），<音效>。
```
#### 8-10秒（收尾期+口播转化）
```
8-10秒：
拍法：{镜头角度+景别+运镜方式+构图}
画面内容：{主角收尾动作和表情，产品同框，最终定格画面}
商品露出：{产品1最终画面中的位置和可见特征}
声音：{转化句台词+语气}，（背景音乐收束），<收尾音效>。
```
### 第七部分：结尾约束
```
全片保持主体1、反派1、产品1、场景连续一致，人物外貌严格按第四部分描述，不换装、不换发型；不要生成无关同类产品；不要出现多人同脸；不生成字幕、logo、水印。
```

## 分时段写作要点
### 0-2秒（钩子期）
- **拍法**：低角度/仰拍居多，制造压迫感；手持微晃增加真实感
- **画面**：第1秒必须有动作（摔东西/指人/推门），冲突立刻爆发，只给一个信息
- **声音**：反派台词直接抛出来（一句短句即可），配合摔东西/拍桌子等冲击音效
### 2-5秒（施压期+产品登场）
- **拍法**：从中景推近到特写，聚焦产品登场瞬间
- **画面**：前半段施压升级，后半段产品首次出现，产品必须有清晰特写（本段只放这两件事）
- **商品露出**：产品正面朝镜头，核心外观特征（颜色、logo、造型）清晰可见
### 5-8秒（反转期+爽点高潮）
- **拍法**：多镜头快切（手部特写→效果呈现→反应特写），反转处用慢镜
- **画面**：产品使用状态+效果证明+反派表情崩塌，三者依次呈现，靠剪辑节奏而非台词撑起爽感
- **声音**：对比感强（安静vs嘈杂、无声vs有声），强化产品核心卖点
### 8-10秒（收尾期+口播转化）
- **拍法**：正面中景/近景，固定机位，干净收尾
- **画面**：主角看向镜头方向，产品在前景/手边同框可见
- **声音**：转化句只有约2秒时间，控制在12字以内，清晰有力，音乐利落收束

## 各类型声音设计参考
| 类型 | 背景音乐风格 | 典型音效 |
|------|-------------|----------|
| 霸道总裁 | 紧张弦乐→安静坚定节奏→干净收束 | 文件摔桌声、鼠标点击声对比 |
| 家庭伦理 | 低沉紧张BGM→安静一秒→反转上扬→温暖收束 | 拍桌子声、鼠标咔咔声对比、翻书声 |
| 古装宫斗 | 紧张弦乐渐弱→低沉节奏→鼓点推进→音乐抬升收束 | 奏折摔落声、护甲敲击声、烛火噼啪声 |
| 职场爽剧 | 低沉紧张→电子节拍加快→停顿一拍→利落收束 | 文件摔闷响、打印机吐纸声、人群安静一秒 |
| 悬疑反转 | 低频悬疑推进→突然安静一秒→反转抬升→干净收束 | 空荡办公室回声、抽屉滑轨声、鼠标细微摩擦声 |
