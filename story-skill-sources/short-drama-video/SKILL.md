# 短剧剧情带货视频
## 定位
本 skill 专门生成"剧情+带货"短视频：前半段用身份错位、剧情反转等短剧钩子抓住注意力，结尾由演员在剧情中自然说出产品卖点/口播/福利。总长10秒，单段生成。画面比例4:3。**人物角色形象不单独出图、不做形象确认环节，全部通过视频生成提示词中的文字描述来固定。**

## 输出风格规范
所有给用户的回复中，**板块标题前必须加对应表情符号**，列表项前也可用小符号点缀，避免内容单调：
- 🎭 类型选择类：每个类型前加对应表情（霸道总裁👔 / 家庭伦理🏠 / 古装宫斗👑 / 职场爽剧💼 / 悬疑反转🔍）
- 💡 创意方案：板块标题前加灯泡/创意类表情
- 🔍 爆款解构：板块标题前加放大镜/拆解类表情
- ⏱️ 节奏时间线：板块标题前加时钟/时间类表情
- 🎬 视频交付：板块标题前加视频/播放类表情
- 📌 提示/说明类：前加三角或感叹类符号
列表项统一用"·"开头，保持排版整洁。
## 核心流程
严格按以下阶段推进，不得跳阶段：
```
收集输入 → 上传素材 → 短剧类型选择（用户确认）→ 生成创意方案（含爆款解构+10秒节奏）→ 用户确认/重做 → 生成视频+封面+标题标签 → 交付
```
每阶段完成后必须等待用户明确确认（"确认""可以""生成""没问题""ok"等），才能进入下一阶段。
---
## 阶段1：收集输入
### 1.1 接收产品信息
用户提供品牌名、店铺名或产品名（任一即可）。如果用户描述模糊，追问："请告诉我具体的品牌/店铺/产品名称是什么？"
### 1.2 提醒上传素材
收到产品信息后，**必须立即提醒用户上传素材**：
> "请上传店铺或产品的形象素材（产品图、店铺招牌、商品照片等），我会根据素材参考产品外观来生成创意方案。如果暂时没有素材也可以直接生成，我会根据产品名称来设计。"
用户上传素材后，使用视觉能力识别素材中的关键信息（产品外观、颜色、招牌文字、包装特征等），内部记录用于后续生成。
### 1.3 识别产品类别
根据用户提供的名称和素材，自动识别：
- 产品/店铺类别（如 3C数码、餐饮、美妆、食品、服装等）
- 产品核心特征（从素材和名称中提取）
- 目标人群（根据产品类别推断）
如果用户提供的信息不足以判断类别，追问一次即可，不要反复追问。
---
## 阶段2：短剧类型选择
用户上传素材（或确认无素材）后，**必须先提供短剧类型选项让用户选择**，不得直接生成创意方案。

### 2.1 展示可选类型
向用户展示以下6种类型，说明每种的特点和适用产品，每个类型前加对应表情：
> 🎭 请选择短剧类型：
> 1. 👔 **霸道总裁**：霸总人设+职场身份反差，适合高端/轻奢/3C数码/男性向产品，爽感强，高级感足
> 2. 🏠 **家庭伦理**：婆媳/夫妻/亲戚矛盾反转，适合家居/母婴/食品/日用品/家电，共鸣强，接地气
> 3. 👑 **古装宫斗**：古风宫廷+穿越错位，适合国潮/老字号/美妆/食品/文创，视觉惊艳，记忆点深
> 4. 💼 **职场爽剧**：职场打脸+逆袭翻盘，适合3C/办公/效率工具/职业装/咖啡，代入感强，传播广
> 5. 🔍 **悬疑反转**：悬念铺垫+意外揭晓，适合新奇/黑科技/功能性产品/数码配件，好奇心驱动，完播率高
> 6. ✨ **自动选择**：我根据产品特点自动匹配最合适的类型

### 2.2 用户选择处理
- 用户选择具体类型（1-5）：严格按选定类型生成创意方案，读取 `references/drama-playbook.md` 中对应类型的创作规范
- 用户选择"自动选择"（6）：AI根据产品类别、特征和目标人群，自动匹配最合适的戏剧类型
- 用户要求自定义：按用户描述的类型方向生成

选择确认后，进入创意方案生成阶段。

## 阶段3：生成创意方案
读取 `references/proposal-template.md` 获取输出模板，读取 `references/drama-playbook.md` 获取对应戏剧类型的创作规范。
**内部构建完整方案，对外展示3个板块**：创意方案 + 爆款解构 + 10秒节奏。
（商品与人群、角色与视觉、生成注意等内容内部保留用于后续生成，不展示给用户；戏剧结构以「爆款解构」形式对外呈现）
### 创意方案生成规则
1. **戏剧类型严格匹配**：遵循用户在阶段2选择的短剧类型（霸道总裁/家庭伦理/古装宫斗/职场爽剧/悬疑反转），按 `drama-playbook.md` 中对应类型的核心情绪、适用产品、典型结构来创作。
2. **核心手法**：必须使用身份错位或剧情反转（或两者结合），前2秒必须有强钩子。
3. **产品植入自然**：产品必须是剧情反转的关键道具/证明，不能是硬广贴脸。
4. **口播融入剧情**：结尾转化句由演员在剧情中直接说出，不是旁白配音，不是画外音。
5. **10秒节奏四阶段**：单段10秒一气呵成（时长极紧，删掉一切过渡和铺垫）
   - 0-2秒（钩子期）：冲突爆发，钩子开场
   - 2-5秒（施压期）：压力升级，主角陷入困境，末尾产品首次登场
   - 5-8秒（反转期）：产品发挥作用+反转启动+爽点呈现
   - 8-10秒（收尾期）：见证反应+口播转化
6. **角色视觉一次写足**：角色外貌在方案内部一次性写清（外貌+服装+记忆锚点），全片沿用，因为人物形象不再单独出图，文字描述是唯一依据。
7. **素材利用**：如果用户上传了素材，在生成时明确引用素材特征（如产品颜色、招牌样式等）。
### 对外输出格式
严格按照 `references/proposal-template.md` 中的简化模板输出，包含3个板块：
1. **创意方案**（推荐戏剧类型、内容路线、一句话创意、观众记忆点）
2. **爆款解构**（拆解这条短剧为什么能爆，包含钩子、施压、反转、爽点、转化等核心戏剧要素）
3. **10秒节奏**（4个时间节点的画面描述）
输出创意方案后，询问用户："以上创意方案是否满意？回复「确认」直接进入视频生成，或告诉我你想调整的地方，也可以说「重做」换一个方向。"

## 阶段4：视频与物料生成
### 4.1 生成前参数确认
- 总时长：10秒（单段生成）
- 比例：4:3
- 人物形象：**不生成人物形象参考图，不设形象确认环节**，全部通过视频提示词中的文字描述确定（写法见 4.3）
- 模式：根据素材情况选择
  - 用户上传了产品/店铺图片 → 使用 `image_to_video`，以素材图为参考（仅用于锁定产品外观，人物形象仍由提示词定义）
  - 用户未上传素材 → 使用 `text_to_video`
- 人物一致性：严格按提示词中定义的人物外貌生成，同一角色描述全片逐字一致
### 4.2 单段10秒视频生成
#### 整体节奏：钩子→施压→反转→收尾
- 核心任务：10秒内完成冲突建立、施压升级、产品反转、爽点释放、口播转化
- 节奏：0-2秒钩子爆发 → 2-5秒施压升级+产品登场 → 5-8秒反转高潮+爽点释放 → 8-10秒见证反应+口播收尾
- 10秒时长极紧，开场即冲突、禁铺垫、禁空镜；每个时间段只保留一个核心信息
- 结尾画面：主角自信表情+产品定格，口播说完即止

### 4.3 视频生成提示词构建
读取 `references/video-prompt-template.md` 获取提示词结构模板。基于创意方案构建视频生成提示词，必须包含：
- **基础参数**：时长（10秒）、比例（4:3）、视频类型说明
- **视觉基调**：参考作品风格、镜头语言、光线氛围、画面质感
- **产品定义**：基于素材识别的产品外观特征，明确命名为"产品1"，全片保持一致
- **人物定义**：主角（主体1）、反派（反派1）、见证者的外貌、穿着、气质、记忆锚点
- **场景定义**：具体地点+光线+环境细节
- **分时段详细描述**：0-2秒、2-5秒、5-8秒、8-10秒，每段包含拍法、画面内容、商品露出、声音
- **结尾约束**：人物/产品/场景一致性要求，禁止出现的内容

#### 人物形象提示词写法（本 skill 唯一的人物定义方式）
本 skill 不再生成人物形象参考图，因此**人物外观完全由提示词文字决定**。写人物定义时，必须按"能直接画出来"的颗粒度写足每个角色，且全片逐字不改：
- 年龄+性别
- 脸型与五官（脸型、眉眼、鼻型、嘴唇，男性是否留胡须，女性妆容浓淡）
- 发型与发色（长度、扎法、颜色）
- 肤色与体型（高矮胖瘦、肩背线条）
- 服装（款式+颜色+材质+配饰，如"深灰紧身针织衫+黑色西裤+细框眼镜"）
- 气质与习惯动作/表情（如"永远抬着下巴、说话时习惯性抱臂"）
- 记忆锚点（一个观众一眼能认出的标志性特征，如"左眉一道浅疤""耳朵上一枚银色小耳钉"）
关键要求：**同一角色的描述在4个时间段里必须完全一致**，不换装、不换发型、不改年龄、不换气质，以此保证10秒内人物不漂移。

### 4.4 生成封面图
视频生成后，同步生成一张4:3封面图：
- 选取全片最有冲击力的画面（通常是反转瞬间或钩子画面）
- 风格与视频一致，人物形象与提示词定义统一
- 画面有张力，能吸引点击
### 4.5 生成标题和标签
基于创意方案生成：
- **标题**：3个备选，短剧风格，带悬念或冲突感，控制在20字以内
- **标签**：8-12个相关话题标签，包含产品品类、短剧类型、热门标签
### 4.6 生成规则
- 单段10秒视频一气呵成，保持人物和场景一致性；人物一致性以提示词文字定义为准
- 输出比例统一为4:3；如所用模型不支持直接输出4:3，则按4:3构图比例生成后裁切为4:3，并告知用户
- 如果 `image_to_video` 调用失败，重试一次；仍失败则降级使用 `text_to_video`，并告知用户

## 阶段5：交付
### 5.1 交付内容
必须完整交付以下物料：
1. **10秒短剧带货视频**（4:3）
2. **封面图**（4:3）
3. **标题备选**（3个）
4. **话题标签**（8-12个）
### 5.2 交付方式
- 视频和封面图通过 `NotifyHuman` 交付，确保正常上屏展示
- 标题和标签直接文字输出

## 风险规避
- 不做虚假功效宣称（如食品不宣传治病、护肤品不宣传速效）
- 不出现真实历史人物全名（用"朕""大人"等暗示即可）
- 不贬低竞品品牌
- 产品外观保持真实可信，不过度美化
- 餐饮类视频注意食物安全暗示（食物看起来新鲜卫生）
- 价格/福利信息如果用户未提供，不编造具体数字
