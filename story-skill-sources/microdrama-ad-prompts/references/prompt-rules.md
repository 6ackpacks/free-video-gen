# Seedance 30秒提示词规范

第4步至第5步读取本文件。第5步只编译已确认内容，不新增人物、情节、卖点、包装或口播。

2. 固定模块顺序

## 1. 模式与固定规则

先内部判断 `commerce_mode`：剧情包含产品使用、品牌揭晓或转化动作即为带货。不要向用户说明判断过程。

所有模式统一执行：

- 30秒、9:16竖屏，固定六段，每段5秒。
- 前10秒只有两个独立剧情点，每段一个。
- 每段发言人物不超过2人，台词不超过2句，动作保持简单。
- 每段融合画面、运镜、动作、台词、环境音和背景音乐。
- 每段末尾标注光影色调与画面风格。
- 运镜突出丝滑推拉、跟拍和情绪特写，避免频繁碎切与复杂调度。
- 最终只输出提示词本身，不附前言、说明、备注或核对结果。

带货模式追加：

- 0-20秒：不接触、不露出产品。
- 20-25秒：自然使用产品，只说功能或使用感受，不说产品名称，不突出正面品牌标识。
- 25-30秒：清楚展示产品正面和品牌标识，逐字念出已确认固定口播。
- 产品名称与固定口播只能出现在25-30秒。

非带货模式省略植入和带货负面项；20-25秒写关键行动，25-30秒完成纯剧情闭环。

## 2. 固定模块顺序

不得修改名称、顺序或标点：

1. `【视频规格】`
2. `【整体画质与美术风格】`
3. `【三段式光影色调过渡】`
4. `【运镜与转场的整体要求】`
5. `【声音规范】`
6. `【植入要求】`，仅带货模式
7. `【整体生成质量要求】`
8. 六段时间戳
9. `【硬性执行规则】`
10. `【负面提示词】`

## 3. 六段节奏

固定拆分为6段，每段5秒。每段标题使用「时间 + 四字小标题・四字小标题」，段落内融合画面内容、运镜方式、人物动作、人物台词、环境音效、背景音乐六大要素，每段末尾标注本段光影色调与画面风格属性。

剧情节奏严格遵循以下固定逻辑。前10秒仅设置2个核心剧情点，单段发言人物不超过2人，精简动作，避免复杂互动：

- **0-5秒 开篇入题**：呈现首个核心场景或冲突场面；单一场景、单一核心信息，出场人物精简，发言角色不超过2人，交代背景或核心矛盾，运镜以全景推近情绪特写为主。
- **5-10秒 冲突递进**：呈现第二个核心剧情节点；冲突或剧情递进但人物不增加，发言角色不超过2人，聚焦单一核心动作，避免多人物交叉互动，运镜配合剧情节奏切换。
- **10-15秒 情绪落点**：剧情推向低谷或关键僵持节点；核心角色独处或聚焦单人情绪，完成情绪沉淀，运镜以跟拍加慢移特写为主。
- **15-20秒 转折觉醒**：核心角色平复情绪，下定决心或出现转机，铺垫后续行动动机；带货模式全程不接触、不露出带货产品，仅核心角色单人出镜。
- **20-25秒 行动落地**：核心角色执行关键动作；带货模式自然使用带货产品，特写使用细节与状态变化，人物精神面貌同步转变，仅描述产品功能与使用感受，不提品牌名称。
- **25-30秒 收尾定格**：核心角色定格最终姿态，剧情闭环收束；带货模式自然展示产品正面、清晰露出品牌标识，严格念出固定口播台词，镜头推近并定格产品与人物同框画面。

标题格式固定为：

```text
0-5秒｜四字小标题・四字小标题
```

两侧标题各为四个汉字。默认语义：

```text
0-5秒｜冲突乍现・矛盾入局
5-10秒｜冲突升级・危机迫近
10-15秒｜情绪跌落・僵局凝结
15-20秒｜内心觉醒・转机初现
20-25秒｜行动破局・产品介入
25-30秒｜反转收束・同框定格
```

每段写成一个连贯段落，段末固定添加：

```text
【光影色调：[本段色调]｜画面风格：[本段风格属性]】
```

## 4. 整体视听与一致性

- 画质：明确清晰度、题材美术、材质细节、人物肤质和商业成片质感。
- 光影：0-10秒冷调或平调；10-20秒由平调转暖；20-30秒明亮收尾。各段末尾标注必须服从这条总线。
- 转场：用动作、视线、遮挡或光线变化自然衔接。
- 声音：递进式短剧背景音乐随情绪变化；人声清晰立体；环境音贴合场景；各音轨比例协调。
- 质量：限制人物数量和动作复杂度，减少换脸、错手、穿模、物品失真和动作断裂。

内部一致性要求，不单独输出：

- 人物：年龄感、脸部、发型、服装、配饰和人数。
- 场景：地点、时间、光线、道具、站位和转场关系。
- 产品：外形、包装色、尺寸、Logo位置和使用方式，仅带货模式。

现代题材保留真实产品形态。古风、仙侠或年代题材只使用第4步已确认的包装适配方案；品牌名称和Logo必须真实，不新增包装文字。

## 5. 负面提示词

按以下顺序组合：

1. 通用基础项，逐字保留。
2. 根据题材和剧情选择2至4项针对性禁用内容。
3. 带货模式追加带货禁用项。
4. 原样加入用户明确提供的禁止内容。

通用基础项：

```text
不要字幕，不要 UI 标识，不要卡通化夸张特效，不要多余闲杂人物，不要浮夸夸张的肢体动作，不要面部崩坏变形，不要物品形态失真，不要多人同框复杂互动。
```

题材补充项：

| 题材 | 针对性禁用内容 |
|---|---|
| 都市职场 | 不要古装或超自然能力，不要无因果升职致富，不要复杂会议群戏 |
| 豪门身份 | 不要靠价格证明人物价值，不要新增家族成员，不要无铺垫改变身份 |
| 重生穿越 | 不要多时间线反复切换，不要两个相同主角，不要复杂时空特效 |
| 古装权谋 | 不要现代建筑、服装或电子设备，不要虚构朝代文字，不要大规模宫斗群戏 |
| 仙侠玄幻 | 不要游戏界面，不要法术遮挡人物和产品，不要把产品表现成治病复活的神物 |
| 情感家庭 | 不要无铺垫暴力羞辱，不要用产品替代沟通，不要突然增加亲属 |
| 悬疑反转 | 不要血腥畸变，不要凭空出现证据，不要虚构监控或鉴定功能 |
| 青春成长 | 不要危险校园冲突，不要成人化权谋，不要生成校名、校徽或成绩保证 |
| 年代创业 | 不要时代错位物件，不要凭空暴富，不要虚构年代标语 |
| 热血传奇 | 不要群体打斗、爆炸或危险特技，不要复杂赛制和多人调度 |

带货禁用项：

```text
禁止前20秒提前露出产品名称与品牌标识，不要浮夸逆袭打脸桥段，不要赛场领奖类夸张反转。
```
