# 30秒微短剧题材指南

本文件仅供第2步推荐和确认短剧题材时读取，只负责题材大类清单与产品题材匹配。

## 目录

1. 题材选择原则
2. 题材大类清单
3. 根据产品类型推荐题材
4. 推荐输出规则

## 1. 题材选择原则

依次判断产品的真实卖点、主要使用场景、目标人群、卖点的可视化程度和适合承载的情绪关系，再推荐题材。

- 优先选择能自然容纳产品使用场景的题材。
- 优先选择目标人群熟悉、容易代入的人物处境。
- 每次最多推荐3个题材，每个题材只说明适配理由，不提前编写人物和剧情。
- 用户指定题材时，定位到同名大类并请求确认，不擅自改成相近题材。
- 题材名称必须严格使用下表标题，不缩写、不合并、不另造同义名称。

| 教育、课程、学习工具 | 职场逆袭；萌宝亲子；大女主；青春校园；热血竞技 |

| 软件、企业服务、创业项目 | 职场逆袭；真假身份；神豪商战；普法反诈 |
| 适老用品、健康生活用品 | 家庭伦理；大女主；普法反诈；中老年情感 |

无法直接归类的产品，先判断它主要解决的是形象、效率、关系、学习、家庭生活、风险、身份表达还是行动支持，再选择承载该价值最自然的题材。

涉及医疗、教育、投资、法律或未成年人时，只根据真实使用场景推荐，不以夸张结果作为适配理由。

## 4. 推荐输出规则

先用紧凑编号列出全部22个题材大类，再给出不超过3个推荐。每个推荐仅包含：

- 题材大类：必须使用上表原名。
- 推荐理由：说明该题材为什么适合产品卖点和目标人群。

本阶段不提前创作剧情。用户确认题材后，再进入爆款剧情原型选择。
