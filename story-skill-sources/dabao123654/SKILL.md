# 视频号短剧带货脚本生成器

## 概述
把视频号微短剧带货的实战打法固化成可执行流程：给定品类/产品/赛道，产出 7-10 分钟一集的微短剧带货剧本（角色设定 + 分集梗概 + 多幕场景剧本 + 产品植入 + 转化 + 系列规划）。目标用户：视频号短剧带货团队、商家自播、MCN 机构。

## 触发场景
- 用户要写 / 生成视频号短剧、微短剧带货剧本（区别于口播短视频）
- 指定赛道（逆袭爽剧 / 情感婆媳 / 职场打脸）、品类、集数
- 给定产品卖点、人设、转化目标（小黄车 / 私域 / 公众号）

## 工作流
1. 收集要素：品类、具体产品 + 核心卖点（1-3 个）、赛道、单集时长（默认 7-10 分钟）、目标集数、人设、转化链路。缺项用合理默认补全并标注。
2. 定结构：按 references/drama_frameworks.md 的「微短剧黄金结构」搭每集骨架（强钩子→冲突升级→反转+产品作解药→爽点释放→双钩收尾）。
3. 角色设定：给 2-4 个角色（人设、动机、情绪弧），保证爽点/共鸣成立。
4. 分集梗概：每集一句话钩子 + 核心冲突 + 本集带货点 + 结尾悬念（引下集）。
5. 场景剧本：按 assets/drama_template.md 写多幕（场号/场景/人物/台词/动作镜头/BGM/时长），前 3 集定生死，每 30 秒一个钩子保持完播。
6. 产品植入：自然融入剧情（主角困境的解药/反转关键），标注植入时机与话术，忌硬广、忌打断情绪。
7. 转化设计：结尾引导（小黄车 / 私信 / 关注公众号 / 加企微），按 references 的「视频号转化链路」写话术。
8. 系列规划：主线弧光、集数节奏、爆款反转节点。
9. 自检：节奏是否够爽够密、植入是否生硬、结尾是否双钩（悬念+转化）、人设是否立住。

- references/case_studies.md：真实爆款拆解库（红烧酱逆袭爽剧 / 后妈珊瑚绒毛巾），含逐条结构时间线与可复用套路

## 要点
- 视频号用户偏熟人/信任/情绪，婆媳情感共鸣强；完播靠"每 30 秒一个钩子"。
- 产品必须当"解药"而非"广告"，否则掉粉。
- 前 3 集定生死：快速立人设 + 抛大冲突。
- 结尾双钩：引下集悬念 + 转化动作，二者缺一不可。
