# 视频号微短剧带货框架库

## 一、微短剧黄金结构（每集 7-10 分钟）
- 0-30s：强钩子（冲突/羞辱/危机）+ 立人设
- 30s-2min：冲突升级，压抑积累（爽剧蓄力）
- 2-5min：反转 / 产品登场（产品作解药）
- 5-8min：爽点释放 / 问题解决，产品功效实锤
- 8-10min：收尾双钩（悬念引下集 + 转化引导）

## 二、赛道套路库
### 逆袭爽剧
- 人设：被轻视的小人物（被嘲穷/丑/废）
- 结构：受辱 → 隐忍 → 反转（产品/能力助攻）→ 打脸
- 带货：产品 = 逆袭关键道具（用了某护肤品被认不出 / 某神器效率碾压）
- 情绪：爽、解气

### 情感 / 婆媳
- 人设：隐忍媳妇 / 偏心婆婆 / 护妻老公
- 结构：矛盾爆发 → 委屈 → 转机（产品化解危机 / 送来温暖）→ 和解或爽反击
- 带货：产品 = 家庭温情载体（食品团聚 / 日百省心 / 护肤宠爱自己）
- 情绪：共鸣、泪点、解气

### 职场打脸
- 人设：被排挤新人 / 背锅老好人
- 结构：被坑 → 忍辱 → 反转（产品/能力翻盘）→ 打脸上司
- 带货：产品 = 职场神器（效率工具 / 形象用品）
- 情绪：爽、代入

## 三、产品植入技巧
- 解药式：主角困境靠产品解决，自然不尴尬
- 对比式：用前用后反差（护肤 / 清洁 / 食品）
- 社交货币：产品成谈资/面子（送礼 / 聚法宝）
- 禁忌：避免直接念参数；避免每集硬塞；避免打断情绪曲线

## 四、视频号转化链路
- 小黄车：剧情高潮后"同款在左下角"
- 私域：结尾"想要的联系 / 加微信"，引企微
- 公众号 / 社群：关注领福利，养粉复购
- 话术模板："同款在购物车，点左下角" / "想要的我私你" / "关注主页，下一集更狠"

## 五、已验证爆款公式（反推自真实爆款）
> 详细逐条拆解见 `references/case_studies.md`（基于 2 条真实爆款视频号短剧的字幕提取，非虚构）。以下为抽象后的可复用骨架，生成剧本时直接套用。

### 6 步黄金结构（实战验证版）
1. **0-30s 强钩子**：极端冲突 / 道德困境一句话炸场（逼婚死逼 / 隐瞒钱信任危机）。3 秒内留人。
2. **30s-2min 冲突升级**：压迫感拉满，弱者被欺负到极点（被卖 50 万 / 孩子被赶出无学费）。攒情绪势能。
3. **2-4min 反转①（情感/认知）**：身份或关系反转（恩人相认 / 后妈其实是圣母）。第一次爽/泪点。
4. **4-5min 反转②（打脸/身份）**：反派被收拾（千亿大小姐身份 / 60 万现金兜底）。第二次爽点，强化主角。
5. **5-8min 产品作解药**：产品解决剧情里**刚发生的真实痛点**（爷爷吃不下饭→红烧酱 / 添人口→毛巾），现场验证。不生硬种草。
6. **8-10min 双钩收尾**：情感金句（升华）+ 行动号召（点赞/进直播间/商品橱窗）。双钩缺一不可。

### 3 条植入铁律（从真实话术反推）
- **铁律 1·解药式**：产品必须解决剧情里刚发生的真实困境，宁可多铺 1 分钟剧情也不硬切广告。
- **铁律 2·三段式卖点**：成分/工艺差异化（松茸提取物 / 高密度珊瑚绒）→ 使用场景扩展（肉/排骨/鱼/土豆 / 脸/手/灶台/车）→ 零门槛承诺（零失败零厨艺 / 9.9 包邮一条不到 5 毛）。
- **铁律 3·价格锚点**：先给线下/常规价，再用直播间价击穿，制造"占便宜"冲动。

### 金句复用范式
- 开头抛的困境，结尾用同一句话升华闭环（红烧酱："人只要吃饱了肚子，再难的坎也能迈过去"）。
- 情感类必出"站队金句"引导点赞（"丈夫的孩子就是我的孩子，进了门就是一家人，同意的点个赞"）。
