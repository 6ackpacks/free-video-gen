# 顾客故事附加模板

本次仅扩展顾客故事／短剧获客。原模板、监控流程、模型路由、任务队列和账号执行方式均保持原样。

## 使用

在现有短剧模板中选择「顾客故事 · 情节获客」写法，可选：情景短剧、剧情反转、真香反转、闺蜜对话、办公室情景剧、探店实测、老板轮岗记、沉浸原声。继续使用原有主体资料、参考图片、用户想法、模型、数量和时长设置。

模板库 API 与工作台的 story 场景共享这八个附加模板。已有目录 JSON 不变；启动时只为工作台补齐不存在的模板 ID，不更新旧模板或项目快照。

## 生成

- 独立模块 `story-acquisition-templates.js` 提供八个剧情结构与十六种开头方向。
- 每条组合主体事实、用户方向、剧情骨架、开头方式、角色连续性和动作可实现性规则。
- 仍使用现有四段时间轴字段与现有品牌事实校验，不引入新的脚本确认步骤。
- 分批生成沿用全批次索引；例如十条分成两个五条请求，后五条使用第六至十条差异计划，不重新从第一种开头开始。
- 工作台改写入口同样为每个视频位置附加差异计划。旧模板不会收到新规则。
- 差异计划是生成指令，不保证模型总能产出不同剧情；现有结构与重复校验继续生效。未增加独立审稿服务或新视频拼接引擎。
