# 最终验收设计依据

日期：2026-10-15。范围：帧间本地工作台的模板选择、底图与视频、设置、成片查看。本文是设计与验收清单，不代表付费视频生成已经通过。

## 采用的公开依据

- [Vercel Web Design Guidelines Skill](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) 与 [官方审查规则](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)：语义控件、可见焦点、异步反馈、图片尺寸、延迟加载、状态与导航。
- [Anthropic Frontend Design Skill](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design/skills/frontend-design)：以实际行业、真实素材与主要任务建立视觉层次；减少无意义装饰与重复说明。
- [web.dev 视频性能](https://web.dev/learn/performance/video-performance) 与 [视频延迟加载](https://web.dev/articles/lazy-loading-video)：封面与按需加载，避免所有视频同时下载。
- [W3C 表单标签](https://www.w3.org/WAI/tutorials/forms/labels/) 与 [表单反馈](https://www.w3.org/WAI/tutorials/forms/notifications/)：字段目的明确，失败有下一步，异步状态可被辅助技术感知。

这些原则应用于现有原生 JavaScript/CSS，不引入 React、不替换前端框架、不安装组件库。

## 本项目的落地清单

| 规则 | 原有问题与位置 | 验收方式 |
|---|---|---|
| 主任务先出现，图片区服务于上下文 | `promotion-ui.js` 的步骤、标题、创意图、预设叠加，占用约一整屏才到素材表单 | 1280×720 下，首屏可看到真实素材入口及本次所选模板；说明横幅不重复第二页已有选择动作 |
| 消费者选择模型，渠道由后台处理 | `studio-ui.js` 设置页暴露 TokenDance/APIMart 和豆包无关模型参数 | 普通设置只显示可选视频模型、豆包账号状态及必要偏好；地址、认证、地域、文本模型放在高级配置 |
| 显示的默认值必须符合实际规则 | 生成偏好文案仍称默认 5 秒 | 环境/服务新建默认 10 秒；时长说明从实际模型能力与类型规则生成，不承诺所有模型任意秒数 |
| 保存、生成、错误都需要反馈 | 长任务容易表现为按钮失效或黑屏；输入改变后的保存缺少明确认知 | 操作开始立即反馈；生成中防重复；出错指出缺失项/重试入口；任务提交不明不自动重复付费 |
| 大画面判断成片，列表只承担挑选 | `.project-video-card>video` 固定 240px，竖屏画面约宽 135px | 每条成片有放大入口、标题、时长、下载；弹层尺寸见下表；关闭停止播放并还原焦点 |
| 视频先准备，再流畅播放 | `media.js` 豆包首播等待下载与转码，默认限速 128 KB/s 且串行排队；界面却称即时按需播放 | 准备状态真实；缓存后读取本机；进度可见；兼容 H.264；Range 请求可用；关闭预览不会继续占用播放器 |
| 保持播放器，不因轮询重置 | 多任务结果更新可能重建已播放节点 | 播放 A 时 B 完成或轮询更新，不重置 A 的播放时间；只更新变化的卡片 |
| 所有素材选择都有撤销路径 | `home-massage-ui.js` 人物/家庭图只能添加 | 每张角色图可查看、移除；移除后底图绑定不指向失效素材；不会重复堆积同一图 |
| 图片按展示大小加载 | `visual-*-v2.png` 单张约 1.9–2.95 MB，模板卡片缺少延迟加载 | 原件保留，界面采用压缩展示版；图片明确宽高/比例；屏外图片延迟加载；无明显布局跳动 |
| 共用组件的依赖完整 | `studio.html` 引入预览脚本但未提供其 `WorkbenchUI.dialog` 依赖 | 所有打开/关闭/上一条/下一条/下载入口均实际点击通过，没有未定义全局错误 |
| 内容层次稳定 | 长标题、提示词、上游错误文本会撑宽卡片 | 360px、390px、1280px、1440px 视口均无页面横向溢出；长文可折叠或换行；按钮不被固定栏遮挡 |

## 最简设置页建议

默认进入“常用设置”，按用户决策排序：默认视频模型、豆包账号状态与管理入口、本地素材/草稿保存说明。模型名称沿用制作页的同一函数；不另外产生服务商下拉。

“生成偏好”展示真实类型默认值与可选画幅。没有实现的偏好不显示假开关。改变默认模型只影响后续新计划，已有计划如需修改应明确提示。

“高级连接配置”默认折叠。内部按图片、文本、视频分组，字段与当前渠道相关。密钥留空保留，不能回显。测试连接说明测试的是已保存配置还是当前输入，避免用户修改后测试了旧配置却误以为已经生效。

## 成片预览尺寸验收指标

以下为本项目产品验收目标，不是上述来源给出的标准尺寸。

| 视口 | 预览目标 |
|---|---|
| 桌面 1280×720 | 弹层可用宽至少 900px，最高 94vh；16:9 视频可见宽至少 760px；9:16 视频可见高至少 480px；信息区不挤压视频主体 |
| 桌面 1440×900 | 9:16 视频可见高至少 640px，16:9 可见宽至少 960px；关闭、下载、前后切换都可见 |
| 手机 390×844 | 弹层覆盖可用视口，取消侧栏占位；视频区宽至少 358px 或按竖屏高度限制等比缩放；竖屏可见高至少 560px；横屏宽至少 358px；工具栏换行不遮挡画面 |
| 手机 360×640 | 竖屏可见高至少 410px；横屏可见宽至少 328px；关闭与下载始终可触达；不足高度时信息滚动，视频保持完整 |

共同要求：采用 `object-fit: contain` 保留全画面；不拉伸、不裁切字幕；播放原生控件可用；触屏主要按钮至少 44×44 CSS 像素；键盘可关闭、切换并识别焦点；遵守减少动态效果偏好。

加载验收分开记录：已缓存文件首帧、未缓存文件准备时长、转码准备时长、拖动进度响应。不能把网络下载耗时记成“播放器本地卡顿”，也不能用已缓存表现代表所有首次访问。未缓存/无网/链接失效均须有可理解反馈和恢复路径。

## 最终检查记录要求

每类模板至少保留一条豆包实生成记录，记录行业、模板类型、具体动作、时长、输入素材、任务编号、状态、可播放链接与人工质量结论。前端模拟测试、接口测试、真实生成与人工画面验收分别记录；失败与未验证项目保留在最终待确定项中。

## 辅助审查复验记录

以下为 2026-10-15 本地界面复验，视口 1440×900、1280×720、390×844。所有写入均被浏览器夹具截获，未触发真实生成或缓存；播放器使用本地 H.264 测试文件。结果不会替代真实成片的画面质量验收。

- `scripts/e2e/final-design-review.py`：设置默认隐藏渠道名称，保存失败回滚；页面无横向溢出；视频放大/关闭正常；播放大屏时原页面视频暂停；隐藏的重新加载控件计算样式为 `display:none`。截图与测量：`data/e2e-final-design/review.json`。
- `scripts/e2e/release-gallery-review.py`：真实只读目录中 27 个验收卡片，检查行业、完成状态、待调整标记；足浴筛选 4 条已完成时，大屏播放列表总数为 4，标题包含足浴；三视口无页面错误或横向溢出。实时任务总数会继续变化。证据：`data/e2e-final-design/release-review.json`。
- `scripts/e2e/settings-template-buttons-review.py`：通用/模型与账号/生成偏好 tab、普通及高级连接检测、保存失败恢复按钮、取消折叠通过；搜索无结果空态正常；创建模板必填校验与失败文案存在；项目名称为空不能继续，创建项目失败会显示错误。证据：`data/e2e-final-design/buttons-review.json`。

补查发现并交主 Agent 修复的事项与最终回归：

1. **已关闭**：现代中心新增“管理动作模板”入口。三个视口实测进入管理、打开编辑、归档、切换已归档、恢复、返回模板类型均通过。模板收藏没有历史产品按钮与后端字段，属于未实现的新能力，不作为本轮修复验收项；素材和作品收藏是另外的功能。
2. **已关闭**：创建项目失败新增重新尝试、返回选择模板、查看已有项目。三个视口实测失败后返回选择正常。
3. **已关闭**：新建与编辑模板均有保存锁和弹窗内反馈。延迟响应夹具中重复提交只产生一次 POST，失败后状态文字可见且控件恢复。

最终回归证据仍为 `scripts/e2e/settings-template-buttons-review.py` 与 `data/e2e-final-design/buttons-review.json`。写入全部被夹具拦截，三个视口均没有页面异常。当前文档列出的辅助审查问题均已完成回归，真实生成成片的质量与账号排队情况由主 Agent 的独立验收记录确认。
