## 播放与下载故障矩阵

| 操作 | 故障注入 / 恢复 | 已验证结果 | 脚本 |
| --- | --- | --- | --- |
| 批量下载启动 | POST 返回 503 | 显示下载服务不可用提示，无未捕获异常 | `media-failure-audit.py` |
| 批量下载状态查询 | 第一次 GET 返回 503，点击重新检查后返回已完成 | 弹窗显示明确错误；可重试；恢复后显示有效 ZIP 下载路径 | 同上 |
| 作品详情播放 | 本地预览接口返回 404 | 显示无法播放说明及重新加载按钮；点击可重新读取 | 同上 |
| 放大预览 | 点击放大，缓存接口返回 503 | 大屏弹窗成功打开；`WorkbenchUI.dialog`、`WorkbenchUI.preview`、`VideoPreview.open` 均存在；显示错误并提供重试 | 同上 |
| 单条视频下载 | 放大预览中的下载按钮，缓存接口返回 503 | 下载准备弹窗正常打开；错误可见；没有缺失全局函数错误 | 同上 |

上述故障测试拦截了所有外部媒体请求。它证明播放器和下载入口的错误处理与依赖完整性，不证明任意远程视频都能解码、不证明真实带宽速度，也没有实际下载 ZIP 或打开系统保存对话框。

## 布局及稳定性范围

- 8 个主入口：制作台、模板、项目、素材、作品、设置、复刻、账号。
- 入口检查宽度为 1440 / 760 / 390；26 类型制作流程也检查这三种宽度，均无横向溢出。
- 项目素材专项覆盖 390–1500 宽度；监控专项覆盖桌面与手机。
- 监控专项确认任务轮询保留已存在的播放器节点；没有对数千条作品、慢磁盘、大量同时生成任务做压力测试。
- 脚本默认是无界面 Chromium。Electron 原生登录窗口、系统文件权限、真实网络和操作系统保存框属于人工 / 真机验证范围。
