# 帧间一期制作台升级

原本地服务、Electron 登录、生成适配器、媒体仓库与字幕处理继续使用。默认首页 `/studio`，原入口保留。安装依赖后使用现有 `npm run desktop` 或 `npm start` 启动；服务端口与密钥仍来自本机配置。

一级入口：`/studio`、`/replicate`、`/templates`、`/works`、`/assets`、`/accounts`；辅助设置 `/settings`。

制作路径为选择多个模板 → 每个模板设置数量、时长、创作想法和图片映射 → 生成并编辑提示词 → 确认脚本 / 分配 → 任选一条试片或直接批量 → 我的作品。非短剧默认 5 秒且最多 15 秒，实际可选时长按服务能力校验。按摩默认逐张制作，其余场景可使用共用、自定义及分镜分配。数量不与底图数隐式相乘。

底图生成任务持久化，参考图片用于图像重构。完成图自动进入素材库并标为待确认。失败项可单独处理；未知提交先用真实上游编号核对，不自动重新收费提交。作品、模板和素材均读取真实持久化数据，不使用演示结果。

模板保存不可覆盖内置模板，个人模板形成版本历史。复刻预设保留原 ID、解析来源、变量、节奏与动作包快照，进入模板中心后可直接复用。采纳有效试片会抵扣一个输出槽；内容、图片、时长或动作包变化时原试片失效。提交使用请求标识和任务记录恢复避免重复生产。

新模块：

| 模块 | 用途 |
| --- | --- |
| studio-domain.js | 模板版本、项目计划、映射、就绪校验、试片匹配 |
| studio-service.js | 原内容包及资料接入、后台提示词、视频队列桥接 |
| studio-images.js | 可恢复底图任务、素材落库与单张异常处理 |
| studio-api.js | 模板、项目、素材、作品下载及核对接口 |
| studio-connections.js | 白名单配置与 Windows DPAPI 密钥保存 |
| studio-ui.js / studio-ui.css / studio.html | 共用制作、模板、素材、作品、账号、设置界面 |
| replica-adoption.js | 原复刻入口的试片匹配与剩余数量计算 |

`data/studio.json`、`data/studio-drafts.json`、`data/studio-image-tasks.json` 使用新功能数据；媒体文件仍保留在原仓库。连接配置仅保存用户明确提交的字段，前端只读取密钥是否已配置。初始化按已有模板 ID 去重，不改变旧作品或其原文件。旧资料缺少来源、版本或原片时明确显示缺失，不补造。

扩展内容包沿用 `content-packs/<id>/pack.json` 配置、现有引擎与动作定义，进入同一制作台，不需要增加一级导航。使用 `npm run build` 检查 JavaScript 语法、页面静态资源和内容包；`npm test` 当前 101 项通过。

本次验证包括真实 10 条提示词、已有视频播放和 MP4 全量解码、完成 / 失败混选 ZIP、真实模板版本保存、草稿恢复、连接检查与 1280 / 1100 / 700 像素布局。没有在这次升级验收中提交新视频或图片付费生成，外部成片质量、实际试片抵扣的服务账单、参考生图效果仍需现场生成验收。账号失效及无账号条件用隔离测试覆盖，没有改变正常账号会话。

回退先停止服务、备份当前 data，并对升级提交执行 Git revert。新增 studio 文件可以保留，旧代码不读取；若恢复开发前业务 JSON，必须逐项处理期间新增任务，先核对已提交的外部编号，不直接覆盖当前队列。
